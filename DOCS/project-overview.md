# MonsterAR 專案快速理解指南

## 🎯 專案概述

**MonsterAR** 是一個結合心理健康治療的 AR 互動遊戲，玩家通過手機攝影機掃描卡片，與代表社交痛苦的 3D 惡魔互動，並通過正確的卡片組合來「封印」惡魔。

### 核心概念
- **治療主題**：8 種社交痛苦（孤單、偏見、拒絕、羞恥、壓迫、無助、背叛、忽視）
- **互動機制**：AR 卡片掃描 + 策略性卡片配對
- **目標用戶**：需要心理健康支援的使用者

## 🛠️ 技術規格

### 開發環境
- **Unity 版本**：2022.3.2f1 (LTS)
- **AR 引擎**：Vuforia 10.29.6
- **目標平台**：Android/iOS
- **程式語言**：C#

## 🎮 遊戲流程

### 1. 啟動流程
```
啟動畫面 → 主選單 → 惡魔選擇 → 卡片選擇 → AR 掃描 → 遊戲結果
```

### 2. 核心玩法
1. **選擇惡魔**：從 8 種社交痛苦中選擇一種
2. **卡片配對**：選擇 R、O、A 三種卡片的組合
3. **AR 掃描**：掃描實體卡片呼叫 3D 惡魔
4. **封印判定**：根據卡片組合決定成功或失敗
5. **結果呈現**：顯示成功動畫或失敗提示

### 3. 勝利條件
每個惡魔都有特定的卡片組合要求：
- **忽視惡魔**：O≠3, R∈{3,8}, A∈{3,7}
- **偏見惡魔**：O≠6, R∈{4,5}, A∈{2,8}
- **拒絕惡魔**：O≠1, R∈{1,6}, A∈{1,4}
- *(其他惡魔配對規則詳見 architecture.md)*

## 🔧 快速上手

### 開啟專案
1. 使用 Unity 2022.3.2f1 開啟專案
2. 確保 Vuforia 正確配置
3. 載入 `SampleScene.unity` 主場景

### 測試流程
1. **編輯器測試**：使用 Unity 編輯器 Play 模式
2. **設備測試**：Build 到實體設備測試 AR 功能
3. **卡片測試**：準備實體卡片或使用螢幕顯示

### 常見問題
- **AR 無法識別**：檢查 Vuforia 授權和攝影機權限
- **卡片配對失敗**：確認 `DemonsDetectedManager.cs` 中的配對邏輯
- **音效無法播放**：檢查 `AudioManager.cs` 中的音檔路徑
