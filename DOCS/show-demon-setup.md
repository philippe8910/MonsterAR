# 現身按鍵設定指南

## 📋 功能概述

新增的現身按鍵功能實現了以下遊戲流程：
1. **AR掃描** → 惡魔出現（黑影狀態）
2. **選擇卡片** → 「現身」按鍵啟用
3. **按現身** → 煙霧特效 + 惡魔恢復正常顏色
4. **按封印** → 執行原本的封印判定

## 🔧 Unity 設定步驟

### 1. 添加現身按鍵 UI
1. 在 AR 掃描場景中添加新的 Button
2. 命名為 `ShowDemonButton`
3. 設定按鍵的視覺樣式和位置

### 2. 設定 DemonsDetectedManager 腳本
在 `DemonsDetectedManager` 的 Inspector 中：
- **Show Demon Button**: 拖入新建的 `ShowDemonButton`
- **Start Detected**: 保持原有的封印按鍵

### 3. 設定按鍵事件
在 `ShowDemonButton` 的 OnClick 事件中：
- **Object**: 拖入場景中的 `DemonsDetectedManager`
- **Function**: 選擇 `DemonsDetectedManager.OnShowDemon()`

## 🎬 新的遊戲流程

### 📋 完整流程圖：
```
選擇惡魔 → 選擇卡片 → AR掃描 → 惡魔出現(黑影) → 「現身」按鍵可用
    ↓
按「現身」→ 煙霧特效 → 惡魔恢復正常 → 「封印」按鍵可用
    ↓
按「封印」→ 判定成功/失敗 → 成功：封印動畫 / 失敗：扣血重試
```

### 🔄 按鍵狀態變化：
- **初始狀態**：現身按鍵不可用，封印按鍵不可用
- **選擇卡片後**：現身按鍵可用，封印按鍵不可用
- **現身完成後**：現身按鍵不可用，封印按鍵可用
- **失敗重試時**：重置為初始狀態

## 💡 技術實現細節

### 1. 惡魔顏色狀態管理
```csharp
// 暗黑狀態：顏色 * 0.2，無發光
SetDarkState(index) → mat.color = originalColor * 0.2f

// 正常狀態：恢復原始顏色
RestoreNormalState(index) → mat.color = originalColor
```

### 2. 煙霧特效障眼法
```csharp
// 播放煙霧特效
OnScanTargetFX() → Instantiate(scanFxPrefab)

// 延遲 0.3 秒後恢復顏色
StartCoroutine(RestoreAfterDelay(index, 0.3f))
```

### 3. 按鍵權限檢查
```csharp
// 檢查是否可以啟用按鍵
if (卡片已選 && 惡魔已掃描) {
    if (惡魔已現身) → 封印按鍵可用
    else → 現身按鍵可用
}
```

## 🧪 測試步驟

### 基本功能測試
1. **進入遊戲**：確認現身和封印按鍵都不可用
2. **選擇卡片**：確認現身按鍵變為可用
3. **按現身**：確認煙霧特效播放，惡魔變亮
4. **按封印**：確認封印邏輯正常執行

### 重試機制測試
1. **故意失敗**：選擇錯誤的卡片組合
2. **失敗後**：確認現身按鍵重新可用
3. **重新現身**：確認可以重新進行現身流程

## ⚠️ 注意事項

### 相容性
- 保持原有的封印邏輯不變
- 確保快速解鎖功能與新流程相容
- 維持原有的音效和動畫系統

### 效能考量
- 煙霧特效會短暫影響幀率
- 材質顏色變化是即時的，無性能問題
- 狀態檢查邏輯輕量化

### 視覺調整
- 暗黑程度可調整 `darkFactor` 值（預設 0.2）
- 煙霧延遲可調整 `RestoreAfterDelay` 時間（預設 0.3 秒）
- 按鍵 UI 需要設計師提供適當的視覺樣式

## 🚀 部署建議

1. **先測試暗黑效果**：確認惡魔顏色變化正常
2. **再測試按鍵邏輯**：確認按鍵啟用時機正確
3. **最後測試完整流程**：確認整個遊戲流程順暢
4. **多設備測試**：確保不同設備上視覺效果一致
