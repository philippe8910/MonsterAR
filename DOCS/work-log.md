## 2025-07-17 - 新遊戲流程實現

### 完成項目
1. **現身按鈕功能**
   - 將偵測邏輯從封印按鈕移至現身按鈕
   - 實現偵測成功/失敗分支處理
   - 偵測成功時顯示成功UI圖像並啟用惡魔現身
   - 偵測失敗時顯示失敗UI圖像並扣血

2. **遊戲流程優化**
   - 重新設計 `OnShowDemon()` 方法包含完整偵測邏輯
   - 簡化 `OnStartDetected()` 為純封印動畫執行
   - 移除 `WinDetected()` 中重複的成功UI顯示
   - 實現失敗重試機制

3. **UX改善**
   - 新增 `LockAllCards()` 方法鎖定卡片選擇
   - 惡魔現身成功後鎖定R O A卡片按鈕
   - 失敗重試時重新解鎖卡片按鈕
   - 防止玩家在成功後誤觸更改組合

4. **音效BUG修正**
   - 修正遊戲啟動時意外播放勝利音效的問題
   - 在 `OnStartDetected()` 加入狀態檢查機制
   - 實現延遲初始化避免初始化順序問題

### 新的遊戲流程
1. **選擇卡片階段**：玩家選擇R O A三張卡片
2. **現身階段**：點擊現身按鈕進行偵測
   - 成功：顯示成功UI + 惡魔現身 + 鎖定卡片 + 啟用封印按鈕
   - 失敗：顯示失敗UI + 扣血 + 可重試
3. **封印階段**：點擊封印按鈕執行封印動畫和勝利轉場

### 技術改進
- 使用 `detectionResult` 成員變數儲存偵測結果
- 優化按鈕狀態管理邏輯
- 改善錯誤處理和調試日誌

### 決策記錄

- **程式碼品質權衡**：focus on 功能完整性，clean code 原則降低優先級

## 2025-07-17 - 黑色貼圖動畫系統完成

### 完成項目
1. **黑色貼圖系統實現**
   - 參考現有 `FadeMaterialToWhite()` 邏輯實現黑色版本
   - 使用 `Color.Lerp(original, Color.black, 0.95f)` 後改為純黑 `Color.black`
   - 確保材質球正確變黑並關閉發光效果

2. **AR掃描出現流程**
   - 新增 `SetCurrentDemonToDark()` 對外接口供AR外掛綁定
   - 惡魔出現 → 立刻變黑 → 播放煙霧特效
   - 加入狀態檢查防止現身成功後重新掃描變黑

3. **遊戲現身流程優化**
   - 修改 `RestoreNormalState()` 為立即恢復正常顏色
   - 立刻變回正常顏色 → 播放煙霧特效作為障眼法
   - 移除延遲恢復機制，改為即時切換

4. **完整遊戲體驗**
   - **掃描出現**：AR掃描 → 惡魔出現且立刻變黑色
   - **選擇卡片**：玩家選擇R O A三張卡片
   - **遊戲現身**：點擊現身按鈕 → 偵測成功後惡魔立刻變回正常顏色
   - **封印執行**：點擊封印按鈕 → 執行封印動畫和勝利轉場

### 技術實現細節
- **黑色效果**：使用純黑 `Color.black` 達到「黑炭」效果
- **時序優化**：確保顏色切換在煙霧開始時執行，不是煙霧結束後
- **狀態管理**：使用 `IsDemonShown()` 檢查防止重複變黑
- **智能檢查**：`SetCurrentDemonToDark()` 包含狀態檢查邏輯
